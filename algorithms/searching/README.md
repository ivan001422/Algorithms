# Поиск

| Задача | Реализации |
| --- | --- |
| Бинарный поиск в отсортированном массиве | [Python](binary_search.py), [C](binary_search.c) |
| Поиск ближайшего числа с выбором меньшего при равенстве расстояний | [Python](nearest_binary_search.py) |
| Поиск в матрице, отсортированной по строкам и столбцам | [Python](sorted_matrix_search.py) |

`nearest_binary_search.py` читает размеры массивов и сами массивы из stdin;
пример ввода и вывода есть в [корневом README](../../README.md).
Поиск в матрице идёт из правого верхнего угла за O(строки + столбцы).

Обходы графов и поиск кратчайших путей находятся в разделе [графов](../graphs/README.md).
