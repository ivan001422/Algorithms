# Комбинаторика

[two_queens.cpp](two_queens.cpp) — подсчёт расстановок двух неатакующих ферзей
на доске `n × n` с помощью рекуррентного соотношения. Размер доски читается из stdin.

Рекурсивный перебор расстановок N ферзей находится в разделе
[перебора с возвратом](../backtracking/README.md).
